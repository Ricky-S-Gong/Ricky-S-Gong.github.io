# Shared site cloud sea

Every section and project detail page uses the selected cached cloud sea and the existing Blue Whale model's native swimming clip. The fixed flight path leaves both edges and moves between close and distant positions. The static poster is rendered from the same scene and appears before the module loads.

The shared `site-background.js` controller loads `home-sky.js` after the first paint. Navigation keeps the same scene running. Background tabs pause; reduced-motion preferences and data-saving connections keep the static poster. WebGL failure falls back to the poster. Cloud lighting is cached and recomputed only for a visible resize, with a short debounce. There are no homepage motion or credit controls; asset attribution appears in Contact.

Home, Research and Contact use an open layout without card surfaces or pointer tilt. Projects retain the original multi-column card grid and full-width featured project, with translucent navy surfaces. The sky mask is 12–48% on desktop and 46% on mobile, making the cloud sea and whale more visible; light text has a subtle shadow. Only the three role headings use mint, blue and gold highlights; the description text remains plain and uniform. Research remains expandable. Desktop Home uses one viewport without scrolling (at least 981px wide and 700px high), with compact spacing on shorter desktop screens. Mobile and small-height windows retain scrolling to keep content readable. The bilingual homepage summary describes target responsibilities in three areas: MLE / AIE, Modelling DS (including financial risk and fraud), and Product DS. These are career interests, not claims of prior experience. Responsibilities were synthesized from employer postings checked November 1, 2026: [Atlassian ML / AI](https://www.atlassian.com/company/careers/details/26789), [Stripe Fraud Data Science](https://stripe.com/careers/listing/data-scientist-fraud/8113100), and [Airbnb Product Data Science](https://careers.airbnb.com/fr/positions/10191465/).

Run `node tests/home-background.test.mjs`. Browser checks cover desktop and mobile layouts, language switching, shared navigation background, project details and static fallback.

The homepage name is the same in both locales: Ricky Gong, with 宫商羽 beside it at the same font size. `assets/kunpeng/name-kaiti.otf` is a subset of FandolKai-Regular covering the Chinese name and motto, a KaiTi font by Clerk Ma and Jie Su. It is served locally under GPL with the font exception, preserved in `assets/kunpeng/FANDOL-COPYING.txt`. The font exception is retained for this subset. [Upstream source package and original font](https://ctan.org/tex-archive/fonts/fandol). Subsetting changes only glyph coverage, not outlines. To reproduce: `pyftsubset FandolKai-Regular.otf --text='宫商羽“道虽迩，不行不至。”' --output-file=name-kaiti.otf --name-IDs='*' --name-legacy --name-languages='*'`.
The reference at https://oscarxzq.github.io/ embeds its Chinese name as `images/xzq_character.png`, so the exact font cannot be identified from CSS. FandolKai is used as a similar standard KaiTi style, not claimed as an exact match.

General Chinese text uses `assets/kunpeng/site-songti.woff2`, a compressed FandolSong-Regular subset covering the 948 Chinese characters and punctuation currently present in `script.js`, `projects-data.js`, `project-detail.js`, `index.html`, `project.html` and `locale.js`. Latin typefaces retain priority. Name and motto use KaiTi; the poem retains its calligraphy font. This Songti subset shares `FANDOL-COPYING.txt` and its font exception. Regenerate the subset when adding Chinese copy; system Songti/SimSun remains the fallback for uncovered characters.

A speaker button in the introduction reads 宫商羽 using the browser/device speech engine on user click. It prefers a mainland Mandarin voice, sets `zh-CN` and a slightly slower rate, and shows a status message if playback fails or is unavailable. There is no autoplay, remote audio asset or synthesized voice file. Voice availability and pronunciation quality depend on the device. Run `node tests/name-audio.test.mjs`.
